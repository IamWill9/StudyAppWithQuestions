# SC-500 source notes

Select **SC-500** in the exam picker after starting `python main.py`. Progress, missed questions, and scores are stored separately in `data/sc-500`.

The bank comes from the supplied 117-page `SC-500_en.pdf` and includes all 120 questions:

| Topic | Questions |
| --- | ---: |
| Manage identity, access, and governance | 36 |
| Secure storage, databases, and networking | 36 |
| Secure compute | 24 |
| Manage and monitor security posture | 24 |

There are 84 multiple-choice questions and 36 image-based questions represented by ordered menus. Choices can be reused, including repeated Yes/No answers. All boxes must match to score a question, consistent with the existing app. The 114 original source images include case-study tables, question figures, and solutions. Solutions appear after submission; click an image to open it at full resolution.

Each question retains its source number, PDF page references, explanation and available reference links. Shared case-study text and tables accompany 17 questions so they remain usable when shuffled. Questions 73 and 97 refer to the Fabrikam scenario introduced earlier in the PDF; that scenario is included with both.

## Source discrepancy

Question 96 has an internal conflict: the printed answer key selects **E (Key Vault Secrets User)**, while the explanation names **C (Key Vault Crypto Service Encryption User)**. Scoring preserves the printed answer E. The result explanation prominently notes the discrepancy and retains the original explanation.

Answers are transcribed from the supplied document. They have not been independently certified against current Microsoft product behaviour. The PDF itself is not included in the repository.

## Validation

```powershell
python main.py --validate --file questions/sc-500.json
python -m pytest tests -q
```

Tests check all question IDs, answer mappings, all 114 images, restored case-study context, the source discrepancy, correct and incorrect submissions for every interactive question, exam selection, and storage isolation across all three exams.
